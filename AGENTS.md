# Repository Guidelines & Automation Rules

## Git Workflow Rule
- **Automatic Commit After Code Execution**:
  Setiap kali selesai melakukan modifikasi kode atau penambahan fitur sesuai instruksi pengguna, selalu buatkan git commit lokal dengan pesan commit yang deskriptif dan relevan (menggunakan format Conventional Commits, misalnya: `feat: ...`, `fix: ...`, `refactor: ...`, `chore: ...`).
- **Do Not Push**:
  JANGAN melakukan `git push` ke remote repository kecuali jika ada instruksi eksplisit dari pengguna.
